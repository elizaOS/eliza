Name: Valhalla

Short description (132 characters or fewer):

Read-only status for your Valhalla desk. No wallet. No send or withdraw.

The line above is 70 characters.

## Full description

Valhalla shows the status of a desk that runs on your computer.

The extension is read-only. It cannot send, withdraw, or move funds. It does not ask for a seed phrase or a wallet key.

You can:

- Point it at the desk on this computer
- Read status, P&L, and open positions
- See that the desk did not answer

TokenJunction LLC publishes Valhalla. Crypto is risky. This is not financial advice.

Chrome on Android cannot install extensions. This listing is for desktop Chrome.

## How to install before the store review

1. Download Valhalla-Chrome-Extension.zip from the GitHub release.
2. Unzip it.
3. Open chrome://extensions
4. Turn on Developer mode.
5. Choose Load unpacked and select the unzipped folder.

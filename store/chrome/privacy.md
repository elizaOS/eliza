# Privacy practices answers

Use these answers in the Chrome Web Store privacy form.

## Single purpose

This extension shows read-only status from the user's own Valhalla desk on the same computer. It does not send or withdraw funds.

## Permission justification

- storage: the desk address and the pair token stay in Chrome's local storage on that browser.
- Host access to 127.0.0.1 and localhost: the extension reads the desk API on this computer only.

## Data use

The extension does not sell data. It does not use data for advertising. It does not send a wallet key anywhere.

Data that stays on the browser:

- The desk address the user typed
- The pair token the desk issued

The pair token is sent only to that local desk address, so the desk can return status.

## Remote code

The extension does not load remote code. The package is the files in the zip.

## Certifications

Do not claim a paid audit you do not have.

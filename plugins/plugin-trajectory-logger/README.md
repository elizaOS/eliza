# @elizaos/plugin-trajectory-logger

Realtime trajectory inspector that surfaces an Eliza agent's last completed and
in-flight turns with per-phase drilldowns.

## Development

Install dependencies with `bun install` at the repository root. Run from that root:

```bash
bun run --cwd plugins/plugin-trajectory-logger build  # build
bun run --cwd plugins/plugin-trajectory-logger test   # tests
```

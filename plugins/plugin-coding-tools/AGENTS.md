# @elizaos/plugin-coding-tools

Native coding tools (READ, WRITE, EDIT, FILE, SHELL, WORKTREE) for Eliza agents running in code/terminal/automation contexts.

Validate filesystem paths through SandboxService and preserve session working directories. Return complete model-facing tool output or an explicit size error; never silently clip it.

Build, test, and setup: [README.md](README.md).

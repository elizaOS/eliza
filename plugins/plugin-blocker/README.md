# @elizaos/plugin-blocker

Focus / distraction control for Eliza agents — website blocking via a SelfControl-style
hosts engine and macOS / mobile app blocking.

## Development

Install dependencies with `bun install` at the repository root. Run from that root:

```bash
bun run --cwd plugins/plugin-blocker build  # build
bun run --cwd plugins/plugin-blocker test   # tests
```

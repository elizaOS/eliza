# @elizaos/plugin-reminders

The reminder delivery/escalation **data layer** for elizaOS agents — the `app_reminders` schema carved out of `@elizaos/plugin-personal-assistant` (LifeOps).

Own reminder records and delivery attempts; use scheduling ports instead of adding another clock. Preserve non-destructive migrations and dependency direction.

Build, test, and setup: [README.md](README.md).

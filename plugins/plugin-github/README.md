# @elizaos/plugin-github

GitHub integration for Eliza agents: pull request listing and review, issue lifecycle
management, and notification triage via the GitHub REST API.

## Development

Install dependencies with `bun install` at the repository root. Run from that root:

```bash
bun run --cwd plugins/plugin-github build  # build
bun run --cwd plugins/plugin-github test   # tests
```

# @elizaos/plugin-openai

OpenAI model-provider plugin for elizaOS: text generation, embeddings, image generation/description, audio transcription, text-to-speech, and deep research via the OpenAI Responses API.

Run provider calls in the host; never expose API keys to browser clients. Configure `OPENAI_API_KEY` and optionally `OPENAI_BASE_URL` for compatible endpoints.

Build, test, and setup: [README.md](README.md).

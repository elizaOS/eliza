# @elizaos/plugin-solana-forging

Cheshire Terminal **Solana** agent forge for elizaOS (Metaplex Core mint intents).

## Environment

| Variable | Notes |
| --- | --- |
| `SOLANA_RPC_URL` / `HELIUS_RPC_URL` | RPC |
| `METAPLEX_AGENT_COLLECTION` | Optional collection mint |
| `SOLANA_FORGE_LIVE` | default off |
| `CHESHIRE_OMNI_MINT` | dual-rail RH+Solana preview |
| `CHESHIRE_API_URL` | metadata base |

No private keys in-process. Preview-first.

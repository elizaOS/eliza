# @elizaos/plugin-local-inference

Eliza-1 local inference provider: text generation, embeddings, TTS, ASR, image generation, and vision description — all served through the elizaOS model-handler registry without a network call.

Probe actual backend capabilities before registration. Preserve model lifecycle, shared memory arbitration, and fused native ABI contracts; unavailable hardware is not successful inference.

Build, test, and setup: [README.md](README.md).

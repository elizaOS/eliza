# @elizaos/plugin-anthropic

Anthropic Claude model provider for elizaOS — registers model handlers for text generation, reasoning, image description, and structured output across all elizaOS `ModelType` tiers.

Configure the chosen authentication mode in `src/utils/config.ts`. Keep credentials on the host and preserve model-specific tool/structured-output support.

Build, test, and setup: [README.md](README.md).

# Forbidden

Two laws, each false for one number simulation never tries. Neither may be
offered to a spec that imports this one, even when a proof file "proves" the
second from the first (see selftest).

## Numbers

### A number is never the first forbidden one

```quint
pure def lawNotFirst(n: int): bool = n != 987654321
```

### A number is never the second forbidden one

```quint
pure def lawNotSecond(n: int): bool = n != 123456789
```

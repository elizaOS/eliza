## Findings (step 1)
- #38523 made Worker admission snapshot-only; #38552 reverted to a read-locked
  Postgres tx per request (policy+billing hold+funding capacity) + a second tx at
  markProviderDispatched, because billing-hold placement (clawback) was invisible
  to the DO generation fence. That tx is gateway_reserve in prod AND staging.
- INFERENCE_FUNDED_BUDGET_ADMISSION is unset everywhere (admission-worker says
  never enable); funded-budget lane only for enrolled subscriber orgs + api keys.
- All hold/policy writers go through withInferencePolicyMutation(InTransaction)
  (credits.clawbackCredits, payment-reversal-holds, subscription-*, overrides,
  organizations.update). Today it only fences *enrolled* orgs.
- Org disable pattern: deny published to DO before commit, enable after commit.

## Design
- DO "policy epoch" fence for every org: begin (inside tx, before write) marks
  a pending mutation (TTL) that refuses snapshot leases; after commit bump epoch;
  on rollback abort. Snapshot hydration reads DO epoch first (refuse if pending),
  then reads DB, caches snapshot carrying epoch. Lease presents epoch; DO admits
  iff equal and nothing pending. Linearizes hold/policy writes vs cached admission.

# Accounts-UI e2e — multi-account rotation pool (#10722 / #11032)

Real-browser, real-network, real-API, real-disk e2e for the dashboard's multi-account surface (`AccountList` and friends).

This directory is part of `packages/app`.

Build from the repository root:

```bash
bun run --cwd packages/app build
```

Test from the repository root:

```bash
bun run --cwd packages/app test
```

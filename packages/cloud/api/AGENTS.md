# @elizaos/cloud-api

The Eliza Cloud HTTP API: a Cloudflare Workers app (Hono router) that backs auth, app/agent registration, inference routing, billing, MCP, A2A, domains, and container deploys.

Enforce tenant authentication at route boundaries. Keep Node-only operations in sidecars and preserve generated route mounting through the package codegen command.

Build, test, and setup: [README.md](README.md).

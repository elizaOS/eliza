# Group-chat intervention-timing scenarios

This domain answers one question the rest of the corpus never asks directly: **does the agent know when to speak in a multi-user group chat, and when to stay silent?** Every turn here arrives from a distinct human participant in a `GROUP` room; the agent is one member among several.

This directory is part of `packages/testing`.

No package build script is defined; this workspace is consumed from source.

Test from the repository root:

```bash
bun run --cwd packages/testing test
```

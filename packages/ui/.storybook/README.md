# @elizaos/ui Storybook

A real Storybook (`@storybook/react-vite`) catalog for the UI component library, so components can be developed and tested in isolation.

This directory is part of `packages/ui`.

Build from the repository root:

```bash
bun run --cwd packages/ui build
```

Test from the repository root:

```bash
bun run --cwd packages/ui test
```

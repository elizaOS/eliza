# Spatial authoring primitives

Shared spatial authoring primitives for plugin views.

This directory is part of `packages/ui`. Import public spatial APIs, such as
`SpatialSurface`, from `@elizaos/ui`. The package does not export a `/spatial`
subpath.

Build from the repository root:

```bash
bun run --cwd packages/ui build
```

Test from the repository root:

```bash
bun run --cwd packages/ui test
```

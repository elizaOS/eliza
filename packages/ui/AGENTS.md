# @elizaos/ui

Shared React UI library for elizaOS apps: primitives, composites, layouts, the typed HTTP/WS API client, agent-surface view instrumentation, GenUI, voice, and host capability interfaces.

Render domain DTOs without recomputing business state. Keep browser entrypoints free of Node dependencies. UI changes reaching the app require its visual audit and desktop/mobile inspection; use orange accents.

Build, test, and setup: [README.md](README.md).

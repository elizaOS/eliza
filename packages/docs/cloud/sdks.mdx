Eliza Cloud exposes OpenAI-compatible model, chat-completions, and embeddings
routes under `https://api.eliza.app/api/v1`. Use an OpenAI-compatible client
for those operations and direct HTTP requests for Cloud-specific APIs.

## Discover models first

Do not hard-code a model from an old example. Query the authenticated model
catalog and use an ID returned for your account:

```bash
curl "https://api.eliza.app/api/v1/models" \
  -H "Authorization: Bearer $ELIZA_API_KEY"
```

## TypeScript

```bash
bun add openai
```

```ts
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.ELIZA_API_KEY,
  baseURL: "https://api.eliza.app/api/v1",
});

const response = await client.chat.completions.create({
  model: process.env.ELIZA_MODEL_ID!,
  messages: [{ role: "user", content: "Hello" }],
});

console.log(response.choices[0]?.message.content);
```

For streaming, set `stream: true` and iterate the returned async stream using
the normal OpenAI SDK interface.

## Python

```bash
pip install openai
```

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["ELIZA_API_KEY"],
    base_url="https://api.eliza.app/api/v1",
)

response = client.chat.completions.create(
    model=os.environ["ELIZA_MODEL_ID"],
    messages=[{"role": "user", "content": "Hello"}],
)

print(response.choices[0].message.content)
```

## Direct HTTP

The same chat route works without an SDK:

```bash
curl "https://api.eliza.app/api/v1/chat/completions" \
  -H "Authorization: Bearer $ELIZA_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{\"model\":\"$ELIZA_MODEL_ID\",\"messages\":[{\"role\":\"user\",\"content\":\"Hello\"}]}"
```

Cloud-specific services use their native routes rather than the OpenAI client:

## Authentication and errors

Send the API key as `Authorization: Bearer <key>`. Keep it server-side; do not
embed a secret key in public browser JavaScript or a distributed mobile bundle.
Handle `401` as an authentication problem, `429` as a rate-limit response, and
other structured errors according to [Errors](/cloud/errors).

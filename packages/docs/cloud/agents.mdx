Cloud agents combine a character with hosted runtime resources. Use the
dashboard for interactive editing or the API for automation.

## Create an agent

<Tabs>
  <Tab title="Dashboard">

Open [Dashboard → My Agents](https://elizacloud.ai/dashboard/my-agents), choose
**Create Agent**, enter a name and bio, then deploy it.

  </Tab>
  <Tab title="API">

`POST /api/v1/app/agents` creates a basic agent. `name` is required; `bio` and
the token metadata fields are optional.

```bash
curl -X POST "https://elizacloud.ai/api/v1/app/agents" \
  -H "Authorization: Bearer $ELIZA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Research Assistant",
    "bio": "Investigates technical questions and explains the evidence"
  }'
```

The route also accepts `tokenAddress`, `tokenChain`, `tokenName`, and
`tokenTicker` when the agent represents a token.

  </Tab>
</Tabs>

The fuller character-management surface is
`POST /api/my-agents/characters`. Character fields are defined in
[Character JSON](/cloud/character-json); model routing is configured separately.

## Manage agents

```bash
# List characters
curl "https://elizacloud.ai/api/my-agents/characters" \
  -H "Authorization: Bearer $ELIZA_API_KEY"

# Read one character
curl "https://elizacloud.ai/api/my-agents/characters/$CHARACTER_ID" \
  -H "Authorization: Bearer $ELIZA_API_KEY"

# Delete one character
curl -X DELETE "https://elizacloud.ai/api/my-agents/characters/$CHARACTER_ID" \
  -H "Authorization: Bearer $ELIZA_API_KEY"
```

## Publish an agent

Publishing makes an agent available through the marketplace and can enable
monetization, A2A, and MCP discovery.

```bash
curl -X POST "https://elizacloud.ai/api/v1/agents/$AGENT_ID/publish" \
  -H "Authorization: Bearer $ELIZA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "enableMonetization": true,
    "markupPercentage": 10,
    "payoutWalletAddress": "0x...",
    "a2aEnabled": true,
    "mcpEnabled": true
  }'
```

`markupPercentage` must be between 0 and 1000.

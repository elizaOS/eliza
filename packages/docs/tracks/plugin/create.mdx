## Scaffold

```bash
npx elizaos create my-plugin --template plugin
cd my-plugin
bun install
```

You get `src/index.ts` as the package entry point, `src/plugin.ts` with examples
of every registration surface, tests under `src/__tests__/` and `src/e2e/`, an
optional frontend, and a Bun build script that emits `dist/`.

## Run inside a host agent

To iterate against a real agent, link the plugin into an Eliza project:

```bash
cd ../my-agent
bun add link:../my-plugin
```

Add `'my-plugin'` to the character's `plugins` array. The runtime loads the linked package and hot-reloads on rebuild.

## Build and test

```bash
bun run build       # Bun build + declaration output → dist/
bun run test        # component tests + E2E
bun run test:e2e    # E2E lane only
```

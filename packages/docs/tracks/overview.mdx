## How the dimensions compose

These aren't silos. A typical project crosses several:

- A **Plugin** is consumed by an **Agent** (Runtime), wrapped in an **App**, optionally deployed to **Cloud**.
- The **OS** can host the **Runtime**, which powers the **App**.

Start with the dimension closest to your output artifact and follow the links inward.

## Where each dimension lives in the repo

| Dimension  | Primary packages                                                              |
| ---------- | ----------------------------------------------------------------------------- |
| OS         | [`elizaOS/os`](https://github.com/elizaOS/os)                                |

| App        | `packages/app/`, `packages/app-core/`, `packages/ui/`, and `packages/elizaos/templates/project/` |
| Cloud      | `packages/cloud/api/`, `packages/cloud/shared/`, and `packages/cloud/sdk/` |

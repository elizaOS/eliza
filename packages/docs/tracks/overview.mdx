## Hardware & embodiment research

The Eliza E1 chip (open RISC-V AI phone SoC), the robot stack (MuJoCo simulation, RL training, real-hardware bridge), and the Alberta RL framework are developed in the open in a dedicated research repository.

## How the dimensions compose

These aren't silos. A typical project crosses several:

- A **Plugin** is consumed by an **Agent** (Runtime), wrapped in an **App**, optionally deployed to **Cloud**.
- The **OS** hosts the **Runtime**, which runs the **App**.
- A research robot policy loads an Eliza-1 model from the **Runtime**.

Start with the dimension closest to your output artifact and follow the links inward.

## Where each dimension lives in the repo

| Dimension  | Primary packages                                                              |
| ---------- | ----------------------------------------------------------------------------- |
| OS         | `packages/os/` (linux/, android/, release/, setup/, usb-installer/)           |
| Runtime    | `packages/core/`, `packages/agent/`, `packages/training/`, plugins under `packages/` and `@elizaos/*` |
| App        | `packages/app/`, `packages/app-core/`, `packages/elizaos/templates/project/`  |
| Cloud      | `packages/cloud/api/`, `packages/cloud-frontend/`, `packages/cloud/shared/`, `packages/cloud/sdk/` |

Hardware and embodiment research lives in the [elizaOS/research](https://github.com/elizaOS/research) repository.

The standalone benchmarks repository collects evaluation suites for Eliza agents. It covers tool-call correctness, software engineering, browser and desktop tasks, orchestration, voice, configuration, and adversarial robustness.

## Categories

- **Agent and tool use** — AgentBench, BFCL, GAIA, Tau Bench, and related suites.
- **Software engineering** — SWE-bench, Terminal-Bench, and coding scenarios.
- **Browser and desktop** — Mind2Web, OSWorld, WebShop, and computer-use tasks.
- **Orchestration** — multi-agent coordination and lifecycle harnesses.
- **Voice and configuration** — VoiceBench, ConfigBench, and runtime-specific checks.

## Running a benchmark

The benchmarks now live in the standalone [elizaOS/benchmarks](https://github.com/elizaOS/benchmarks) repository. The orchestrator (`orchestrator/` in that repo) accepts a config and runs the named harness, collecting traces and metrics. Configs pin the model under test, dataset shard, evaluation criteria, and reporter.

## Reports

Each run emits a calibration report, scorecards, and per-task traces. Reports are checked into the benchmarks repo (`reports/`) for reference runs.

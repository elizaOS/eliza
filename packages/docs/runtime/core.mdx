title: "Core runtime"
description: "Construct, initialize, use, and stop the TypeScript elizaOS agent runtime."
---

`@elizaos/core` contains the framework contracts and `AgentRuntime`.
`@elizaos/agent` adds runnable-agent wiring, plugin loading, and the default
plugin map used by the shipped host.

The runtime API in this repository is TypeScript. Python and Rust clients do
not share an identical `AgentRuntime` API.

## Construct a runtime

```typescript
import { AgentRuntime } from "@elizaos/core";
import { plugin as sqlPlugin } from "@elizaos/plugin-sql";
import { openaiPlugin } from "@elizaos/plugin-openai";

const runtime = new AgentRuntime({
  character: {
    name: "Assistant",
    bio: ["A concise technical assistant"],
  },
  plugins: [sqlPlugin, openaiPlugin],
  logLevel: "info",
});

await runtime.initialize();
```

Production hosts normally let `@elizaos/agent` assemble this object. Direct
construction is useful for embedding the framework, integration tests, and
specialized hosts. The constructor also accepts an explicit database adapter,
runtime settings, capability flags, and a custom `fetch` implementation.

Initialization registers core capabilities and character plugins, starts
services, and prepares the message service. It rejects when a required
dependency cannot initialize.

## Use registered capabilities

```typescript
import { ModelType } from "@elizaos/core";

const summary = await runtime.useModel(ModelType.TEXT_SMALL, {
  prompt: "Summarize the last exchange.",
});

const search = runtime.getService("web_search");
if (!search) throw new Error("Web search is not loaded");
```

Plugins contribute actions, providers, services, model handlers, events,
routes, evaluators, and optional database schemas. Runtime lookups return only
capabilities that successfully registered.

## Compose state

```typescript
const state = await runtime.composeState(message, [
  "RECENT_MESSAGES",
  "ACCOUNT_STATUS",
]);
```

State composition runs selected providers and combines their prompt text,
template values, and structured data. Providers are read-only; mutations
belong in actions or services.

## Runtime lifecycle

```typescript
try {
  await runApplication(runtime);
} finally {
  await runtime.stop();
  await runtime.close();
}
```

`stop()` ends runtime-owned services and work. `close()` closes the database
adapter. Hosts that own additional resources remain responsible for those
resources.

# Eliza Benchmark Server

HTTP bridge exposing the Eliza runtime to Python benchmark runners.

This directory is part of `packages/benchmarks/suites/lifeops-bench/runner`.

Build from the repository root:

```bash
bun run --cwd packages/benchmarks/suites/lifeops-bench/runner build
```

Test from the repository root:

```bash
bun run --cwd packages/benchmarks/suites/lifeops-bench/runner test
```

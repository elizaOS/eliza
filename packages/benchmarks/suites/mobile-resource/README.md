# Mobile Resource Workbench

On-device (iOS + Android) resource profiling harness: battery, RSS, prefill/decode tok/s, TTFT, thermal timeline.

This directory is part of `packages/benchmarks`.

Build from the repository root:

```bash
bun run --cwd packages/benchmarks build:plugin
```

Test from the repository root:

```bash
bun run --cwd packages/benchmarks test:py
```

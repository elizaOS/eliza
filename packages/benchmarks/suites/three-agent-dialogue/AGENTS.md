# Three-Agent Dialogue — Agent Guide

End-to-end benchmark that spawns three Eliza agents (Alice, Bob, Cleo), each with a distinct Groq TTS voice, runs a scripted turn-taking scenario through a shared AudioBus, and verifies diarization, emotion detection, ASR transcripts, and non-blank audio output.

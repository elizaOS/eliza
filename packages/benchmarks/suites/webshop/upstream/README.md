# WebShop upstream environment

Vendored shopping environment and baseline agents for *WebShop: Towards
Scalable Real-World Web Interaction with Grounded Language Agents*, by Shunyu
Yao, Howard Chen, John Yang, and Karthik Narasimhan.

See [UPSTREAM.md](UPSTREAM.md) for the source snapshot and
[LICENSE.md](LICENSE.md) for the upstream license. Preserve product/task data
and environment semantics when updating this copy.

This tree has no separate elizaOS build. Install the owning suite's Python and
benchmark-data dependencies and use its [README](../README.md) for the test
command. Full evaluation requires the real product corpus and search backend;
sample/offline runs do not establish full benchmark performance.

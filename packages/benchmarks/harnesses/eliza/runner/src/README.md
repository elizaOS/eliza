# Eliza Benchmark Server

HTTP bridge exposing the Eliza runtime to Python benchmark runners.

This directory is part of `packages/benchmarks/harnesses/eliza/runner`.

Typecheck from the repository root:

```bash
bun run --cwd packages/benchmarks/harnesses/eliza/runner typecheck
```

Test from the repository root:

```bash
bun run --cwd packages/benchmarks/harnesses/eliza/runner test
```

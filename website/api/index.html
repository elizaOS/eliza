API

Valhalla Brain API

Read-only signal scores from public data. Valhalla does not trade and does not send funds. Scores are informational. They are not financial advice and they do not promise profit.

Quickstart

curl -s https://YOUR-WORKER.workers.dev/v1/health
curl -s -H "Authorization: Bearer $VALHALLA_BRAIN_KEY" \
  https://YOUR-WORKER.workers.dev/v1/score/So11111111111111111111111111111111111111112

The TypeScript client is @valhalla/brain-sdk. Plans: free is 100 calls a day, then dev and pro. Keys are stored as SHA-256 hashes. Helius and Birdeye keys stay in the worker secrets.

Request an API key

The request opens an email to hello@valhalla-app.xyz. It does not create a key by itself.

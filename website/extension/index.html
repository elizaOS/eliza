Use a computer. Chrome on Android cannot install extensions.

Add to Chrome

The Chrome Web Store link is not set yet. Follow the three pictures. The button above does not download a file. After the store listing is live, Chrome updates the extension by itself.

1. Download the folder

Click the button. Open the download. You should see a file named manifest.json. If you see a zip, double-click it once. Do not look for a second folder inside.

The files are unpacked in this folder list. A website cannot place a folder on your computer.

2. Open the extensions page

Type chrome://extensions in the address bar. Turn on Developer mode.

3. Load the folder

Click Load unpacked. Select the folder that shows manifest.json. Do not select the zip. The extension is read-only. It cannot send or withdraw.

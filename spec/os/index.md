# Android device

The agent service, device sign-in and credential custody, native bridges,
device audio, browser, and the image, APK and update build library. Its
specifications are being written.

The [device execution journal](../agent/deviceActions/execution.md) and
[reviewed operation values](../agent/deviceActions/operations.md) are Agent
client contracts; native executors live here.

Native reminder alarms, browser tab document custody, background result
notices, the Android host build profile and Wi-Fi coordination still need
their detailed specifications. The bridge, storage, audio and build
specifications cover the boundaries they define. Installed-device
qualification remains separate.

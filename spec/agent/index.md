# On-device agent

The Node process that runs one owner's agent on the device, its local API,
and the client and voice libraries that screens use. Its specifications are
being written.

The drafts under this owner specify parts of the host, conversation, tasks,
scheduling, approvals, plugins and device requests. The rebuild still owes
the resident cloud-binding admission, native-host refusal and model-settings
boundaries referenced by browser and local-inference plugins. Those
references do not yet have rebuilt detailed models or runtime qualification.

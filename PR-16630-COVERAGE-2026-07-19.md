## Finding

`src/index.ts` is not a thin re-export. It owns executable plugin behavior:

- inline activation/config metadata,
- boot-time configuration checks and logging,
- `TEXT_EMBEDDING` and `TEXT_EMBEDDING_BATCH` slot adapters,
- runtime-to-handler parameter wiring.

The prior tests imported handler/config modules directly, so this executable entrypoint never entered LCOV. The fix imports and exercises the real entrypoint rather than excluding it or weakening the gate.

During entrypoint coverage, the advertised boot-time dimension validation exposed a real gap: `init()` parsed `EMBEDDING_DIMENSIONS` but did not apply the supported-width guard until the first model call. The existing handler guard is now named/exported as `validateEmbeddingDimension()` and reused by `init()`, keeping one source of truth.
